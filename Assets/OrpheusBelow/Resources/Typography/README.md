# Interface typography

Published player builds use **Crimson Text Regular** from the Crimson Text Project Authors / Google Fonts, bundled unmodified under the included SIL Open Font License 1.1.

- Source: https://github.com/google/fonts/tree/main/ofl/crimsontext
- Font: `CrimsonText-Regular.ttf`
- License: `OFL.txt`

The requested **Mythology** font is a local personal preview only, as chosen by the user on 2026-10-29. It resides in the ignored `Assets/OrpheusBelow/Scripts/Editor/LocalTypography/` directory, is loaded only behind `UNITY_EDITOR`, and is neither committed nor included in player builds. Its usage terms stay beside the local font. The resource fallback is always available, so a fresh public checkout works without private files.

Mythology source: https://www.1001fonts.com/mythology-font.html
