## Alpha and slicing evidence

Cerberus PNGs have measured alpha range 0–255 and byte-identical generated/source hashes recorded in its `Generation.md`. Visual gutters have variable spacing; stale manual rectangles were removed and `AtlasLayout.json` requests alpha segmentation. Equal-grid cutting must not be assumed.

The image viewer can expose saturated RGB stored beneath near-zero alpha. A separate charcoal composite of Eurydice candidate 3 confirmed that the apparent red/yellow fringe disappears when alpha is composited correctly. Production PNGs were not altered. Final assets still require source-aware alpha slicing and the main agent's Unity bake/playback checks.

Sheep source exclusion is deliberate, not a frame-count claim: the PNG contains 30 visible drawings and remains unchanged; playback uses only 28 safely isolated drawings.
